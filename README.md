# STRIDE CO. — Footwear Supply

A responsive, static shoe-store demo featuring eight original STRIDE CO. shoe concepts, category filters, search, sorting, favorites, size selection, a shopping bag, and demo promo codes.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `stride-co-store`).
2. Upload **the contents of this folder** to the repository's root. Make sure `index.html`, `script.js`, `style.css`, `.nojekyll`, and the `images/` folder are at the top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to finish deploying; the Pages section will show your public website URL.

All image and code paths are relative, so the site works from a GitHub Pages project URL as well as from the repository root.

## Notes

- This is a front-end demo. The cart, wishlist, and checkout interactions run in the browser; checkout does not process real payments or submit orders to a server.
- Google Fonts are loaded from Google Fonts when an internet connection is available; fallback fonts are defined in the stylesheet.
- Shoe imagery represents visual concepts, not manufactured or safety-tested products.
